# Native workspace revamp — 12 November 2026

The Windows and Android clients now use the same neutral workspace palette as the web app: white surfaces, navy text, a light grey canvas and green primary actions. Windows uses a dark adaptive navigation pane, following the requested QuickBooks direction. Shared tokens and feature metadata match the native themes.

## Navigation and screen changes

| Area | Review and changes |
| --- | --- |
| Workspace and company switching | Android titles name the selected register. A global Create entry action remains available; the register's primary button opens that exact form directly. Windows Create offers four everyday actions before grouped sales, purchase and contact/item menus. Existing company/session isolation is retained. |
| Dashboard | A green net-sales lead card anchors Windows totals. The actual sales/purchase chart and invoice-settlement ring appear immediately below, before everyday tasks. Chart legend markers match their bars. Everyday tasks offer New invoice, Receive payment, Add supplier bill and Record expense. | Invoice, bill, estimate, order, return and expense entry | Existing calculation previews, optional-field disclosure, dirty-draft protection, uncertain-save retry and explicit save actions were reviewed. Android retains Details → Items → Review. Shared form surfaces and typography were updated. |
| Transaction details and payments | Outstanding active invoices/bills expose payment actions; unposted/cancelled records do not. Edit is a secondary Android action. Windows prioritizes next steps, with print/share/edit controls in a responsive grid instead of an overflowing horizontal row. |
| Banking and accounting | Windows reconciliation actions now reflow at narrow widths. Existing statement matching, transfers, cash book, balanced journals, reversals and period controls were reviewed in source. |
| Reports and statements | Windows report export/apply controls reflow. Existing report library/category search, period application, export consistency and GST preparation distinctions were reviewed. |
| Settings, backup and security | Build/API diagnostics are inside About, with plain-language summaries. Existing company/branding/member/security/import/backup ownership and review steps were retained. |
| POS, recurring/reorder and ecommerce | Source review covered held carts, explicit posting/retry, recurring draft generation, stock suggestions and store reconciliation. Existing specialist workflows remain; this revision does not claim a full native runtime pass of each specialist screen. |

## Accounting display corrections

Financial register totals previously included cancelled/unposted invoice and bill amounts under the label “Posted value” on Windows. Android also included unposted amounts in general transaction totals. These are now restricted to active postings. Dashboard invoice collection figures are additionally bounded through the current business date, so future invoices do not inflate today's collection figure. Pure regression cases exercise posted, cancelled, unposted and future records.
