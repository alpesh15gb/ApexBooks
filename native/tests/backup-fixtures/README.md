# Synthetic encrypted-v1 compatibility fixtures

These contain only deliberately synthetic test text. The ASCII test password is
`cross-platform-test-only`; the Unicode test password is
`cross-platform-₹-test-🔒`. They are not credentials or application keys.

C# fixtures are generated by an isolated verbatim copy of the existing
`ApexFiles.EncryptBackup` implementation, including its JSON escaping behavior.
The escaped/reordered variant tests the same established envelope format with
arbitrary property order and escaped base64 characters. Compare plaintext with
`csharp-legacy-v1.bin`. No production/user backup is included.

Android-compatible fixtures use the existing Android writer's JCE parameters
(PBKDF2-HMAC-SHA256/250,000, AES-256-GCM, 16-byte salt, 12-byte nonce, 16-byte tag)
and JSON fields, executed in a standalone JDK test—not on an Android device.
`android-streaming-v1.json` comes from the new streaming utility; all compare
with `android-compatible-v1.bin`. The original Android device implementation
still requires device-side interoperability verification.
